# cyber_bullying
The AI-Powered Cyberbullying Detection System is a machine-learning-based application that analyzes text from social media, chats, comments, or online platforms and determines whether the text contains cyberbullying or abusive content.
The project uses BERT (Bidirectional Encoder Representations from Transformers) to understand the context and meaning of text rather than relying only on individual offensive words.
XAI (Explainable Artificial Intelligence) is added to explain why the model classified a particular message as cyberbullying.
This project proposes an AI-Powered Cyberbullying Detection System using Bidirectional Encoder Representations from Transformers (BERT) integrated with Explainable Artificial Intelligence (XAI) techniques. The proposed system preprocesses social media comments, tokenizes the text using the BERT tokenizer, and classifies the comments into categories such as normal, offensive, hate speech, or cyberbullying. Unlike conventional approaches, BERT understands the contextual meaning of sentences rather than relying solely on offensive keywords, enabling the detection of indirect and contextbased bullying. Furthermore, Explainable AI techniques such as SHAP or LIME are incorporated to provide transparent predictions by highlighting the words and phrases that contribute to the model's decision, thereby improving user trust and system interpretability.
