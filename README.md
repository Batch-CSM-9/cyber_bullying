# cyber_bullying
The AI-Powered Cyberbullying Detection System is a machine-learning-based application that analyzes text from social media, chats, comments, or online platforms and determines whether the text contains cyberbullying or abusive content.
The project uses BERT (Bidirectional Encoder Representations from Transformers) to understand the context and meaning of text rather than relying only on individual offensive words.
XAI (Explainable Artificial Intelligence) is added to explain why the model classified a particular message as cyberbullying.
